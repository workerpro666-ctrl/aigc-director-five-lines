# 實作示例｜階段 A 導演提案

本示例示範技能通過驗收後的**階段 A 產出**：五線完整度驗收表 ＋ 標準分鏡。
示例只到分鏡為止——階段 B（Seedance 提示詞）必須把**整個鏡頭序列放進同一次請求**，因此需要 Shot 1、Shot 2 的分鏡一併成立後才能產出，本檔不預先虛構未定義的鏡頭。

---

## 需求

> 「做一個女孩在列車車廂裡害怕的影片鏡頭。由你導演判斷，但開頭要藏住危險來源。」

使用者已授權導演判斷，因此下列判斷標為「由我暫定」，並於驗收表中明示。

---

### 五線完整度驗收｜夜行區間車 EP1／鏡 03

| 項目 | 狀態 | 已確認內容／待確認問題 |
|---|---|---|
| 導演意圖 | 由我暫定 | 主感受：**被盯上的壓迫**。情緒弧線：警覺 → 確認 → 決定要動前的一口氣。敘事位置：開場第三鏡，觀眾此刻只知道她深夜獨自搭車。排除條件：不得浪漫化、不得滑稽化、不得讓對面乘客顯得善意。 |
| 動作線 | 由我暫定 | 前態：她坐靠窗側、右手握扶手、視線在窗外。起因：對面三排座椅的手機螢幕亮起並誤觸閃光燈一次。動作：眼珠先轉向左前方 → 收緊外套下擺 → 雙腳收回座椅下方（約 2 秒）。結果：鞋跟在地板拖出短促摩擦聲、指節發白。下一條件：下一鏡必須是她與對方的第一次視線接觸，或她起身。 |
| 情緒線 | 由我暫定 | 目標：安靜坐完這段車程。刺激：閃光燈，以及螢幕反光持續朝向她。判斷：先是誤觸，再意識到是持續對著她。微表情：眼珠先轉、眉尾壓低、下頜收緊、吞嚥一次。身體：吸氣變短、右手指節發白、肩線抬高、重心後靠。去向：推向「決定要動」。 |
| 攝影線 | 由我暫定 | 見下方分鏡攝影線欄，滿足強制句法七要素：起始機位 → 拍攝朝向 → 主體方向 → 鏡頭路徑 → 運動觸發 → 視覺結果 → 出鏡承接。 |
| 視覺線 | 由我暫定 | 第一秒主訊息：一個人獨坐、窗外光在流動。延後資訊：對面乘客與手機（先失焦、置於畫面右三分之一邊緣）。焦點：她側臉清晰，三公尺外的對面座椅失焦。光色：頂燈 4300K 冷白實用光，窗外路燈為暖橘掠過。 |
| 剪輯線 | 由我暫定 | 入點：前一鏡她坐下、放下背包的動作尾端與地板的「碰」聲。出點：瞳孔定型、將要轉頭對視的瞬間。接法：沿視線方向接反打。節奏：約 5 秒，前 3 秒慢，閃光後 2 秒收緊。 |
| 資訊埋藏線 | 由我暫定 | 線索本體：對面乘客膝上的手機鏡頭朝向。觀看程度：**隱約不安**（觀眾感到不對，但說不出是什麼）。藏置位置：畫面右三分之一、三公尺外的失焦區，並被她自己的肩與左下座椅靠背邊緣遮住。隱藏理由：車廂晃動、窗外光流吸引注意、她的視線尚未轉過去。揭露機制：手機螢幕反光掃過她臉頰 → 她回望 → 焦點由她側臉轉移至對面座椅上方。敘事後果：觀眾重讀前兩鏡「以為是空車廂」的認知。 |

**生成門檻：** 未通過（須由使用者確認上述暫定假設）。
**下一步：** 1. 主感受是否為「被盯上的壓迫」？ 2. 危險來源是否確定為對面乘客的手機？ 3. 她此鏡是否**尚未**與對方對視（留給下一鏡）？ 4. 鏡長約 5 秒是否可接受？

### 分鏡｜鏡 03：夜行區間車．閃光燈之後

**導演意圖：** 被盯上的壓迫；鏡末落在「決定要動」前的一口氣。

| 欄位 | 分鏡指令 |
|---|---|
| 畫面／空間 | 夜行區間車廂中段。她坐靠窗側，右側是走道；對面三排座椅在畫面右三分之一、約三公尺外。關鍵物件：她手上的外套下擺、座椅扶手、對面座椅上的一支手機。 |
| 動作線 | 閃光燈誤觸（起因）→ 眼珠先轉、收緊外套、雙腳收回座椅下方（動作，約 2 秒）→ 鞋跟拖出短促摩擦聲、指節發白（可見結果）→ 下一鏡：她與對方的第一次視線接觸或起身（下一條件）。 |
| 情緒線 | 想安靜坐完車程（目標）→ 閃光燈與持續朝她的螢幕反光（刺激）→ 先當誤觸、再意識到是對著她（判斷）→ 眼珠先轉、眉尾壓低、下頜收緊、吞嚥一次（微表情）→ 吸氣變短、指節發白、肩線抬高、重心後靠（身體變化）→ 推向決定要動（去向）。**不演出誇張驚嚇表情。** |
| 攝影線 | 起始機位：主角**左後方**、鏡頭高度略高於她的肩（約 1.4 公尺）、距離 1.5 公尺、**中近景**，左下前景為座椅靠背邊緣。拍攝朝向：朝**右前方**、越過她的左肩，將對面三排座椅放在畫面右三分之一。主體方向：她位於畫面中央略偏左，向右前方轉頭；**鏡頭不隨她的視線即刻轉動**。鏡頭路徑：以**固定**為基底，在她吞嚥後沿車廂縱向**極慢向前推 30 公分**，越過左肩進入對面座椅空間。運動觸發：車廂過彎的橫向晃動使她肩膀撞上靠背 → 鏡頭**短暫失焦 0.3 秒**再重新鎖回她的側臉。視覺結果：焦點回到她臉上時，觀眾才看清對面座椅上方有一支手機的螢幕反光。出鏡條件：在她瞳孔定型、即將轉頭對視前切出；下一鏡沿她視線方向接對面乘客的反打。 |
| 視覺線 | 第一秒主訊息：一個人獨坐、窗外光在流動——先讀懂「她是一個人」。延後資訊：對面乘客與手機（先失焦、置於畫面右三分之一邊緣，不得清楚可辨）。焦點與景深：她側臉清晰，三公尺外對面座椅失焦，揭露時以移焦釋放資訊。構圖與遮擋：左下座椅靠背邊緣切掉她半邊身體，形成框中框。光影與色彩：頂燈 4300K 冷白實用光，窗外路燈為暖橘掠過，暗部落在對面座椅之間。運動對比：唯一明顯運動是窗外光流與車廂晃動，人物幾乎靜止。 |
| 剪輯線 | 入點：承接前一鏡她坐下、放下背包的動作尾端與地板的「碰」聲。時長：約 5 秒（前 3 秒慢、閃光後 2 秒收緊）。新資訊：她察覺不對，並把身體收小。出點：瞳孔定型、將要轉頭對視的瞬間。接法：沿視線方向接反打。聲音：車輪低頻規則節奏、車廂金屬摩擦、一次吞嚥、遠處手機訊息提示音；與畫面同一次請求生成。 |
| 不可妥協條件 | 1. 她的所有反應必須由手機閃光燈觸發，不得無故警覺。 2. 剪點前對面乘客與手機不得清楚可見（只能失焦或遮擋）。 3. 情緒只透過眼珠方向、吞嚥、指節、肩線呈現，不得誇張演出。 4. 鏡頭全程僅一次向前微推與一次 0.3 秒失焦，且失焦必須由車廂晃動觸發。 5. 鏡末必須停在瞳孔定型，供下一鏡沿視線反打。 |

## 這個示例示範了什麼

- **先驗收、後生成**：缺口以「由我暫定」明示並等待確認，未直接進入提示詞。
- **攝影線的強制句法**：起始機位、拍攝朝向、主體方向、鏡頭路徑、運動觸發、視覺結果、出鏡承接，七項齊備。
- **情緒以身體呈現**：沒有一個情緒名詞單獨成句，全部落在眼珠、吞嚥、指節、肩線與呼吸。
- **資訊埋藏不等於看不見**：線索有真實畫面位置（右三分之一、三公尺外失焦區）、可感知形式（螢幕反光）與可拍攝的揭露機制（移焦）。
- **剪點對齊資訊峰值**：切在瞳孔定型、對視前一格，而不是等動作全部結束。

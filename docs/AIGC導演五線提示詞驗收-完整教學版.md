## 二、30 秒理解這套技能

- **一句話核心：** 任何影像或影片提示詞都是分鏡的下游產物——先確認**導演意圖**與**五條線**，才允許生成提示詞。
- **兩階段架構：**
  - **階段 A（導演提案）**：輸出「五線完整度驗收表」＋「標準分鏡」。此時**尚未**產生最終提示詞。
  - **階段 B（提示詞總監）**：驗收通過後，才把分鏡逐鏡轉譯為完整 Seedance 提示詞（只轉譯，不創作）。
- **硬性門檻：** 嚴格模式下，只要導演意圖或任一條線為「缺失」，**不得**輸出最終可生成提示詞；必須先補問，或把「由你導演判斷」的授權轉寫為可確認的暫定假設。
- **最大價值：** 拒絕用「電影感、史詩感、手持、8K」等風格詞取代敘事決策；強迫每一次機位、每一次剪點都有可執行的理由。

### 五條線＋一條補充線

| 線 | 回答的問題 | 判定口訣 |
|---|---|---|
| 0. 導演意圖 | 最想讓觀眾感受到什麼？ | 先問感受，不要先問鏡頭、顏色或模型 |
| 1. 動作線 | 事情怎麼發生？ | 前一個動作，必須影響下一個結果 |
| 2. 情緒線 | 人物如何感受？ | 不要演情緒；要演情緒造成的身體變化 |
| 3. 攝影線 | 攝影機如何參與現場？ | 從哪裡拍、朝哪裡拍、角色往哪裡動、鏡頭怎麼動、為何動、在哪裡切出 |
| 4. 視覺線 | 觀眾此刻看哪裡？ | 什麼都清楚，往往就是什麼都不重要 |
| 5. 剪輯線 | 觀眾何時看下一個？ | 動作結束，不等於要等鏡頭結束 |
| 6.（補充）資訊埋藏線 | 伏筆怎麼藏、怎麼回收？ | 不要讓「藏起來」等於「看不見」 |

# AIGC 導演五線提示詞驗收

將任何影像或影片提示詞視為分鏡的下游產物。先確認**導演意圖**與五條線，後生成提示詞。不得以「電影感、史詩感、手持、8K」等風格詞取代敘事決策。

> **硬性規則**：在預設的嚴格模式中，只要導演意圖或任一條線為「缺失」，不得輸出最終可生成提示詞。先補問缺口，或將導演提出的明確授權判斷轉寫為可確認的暫定假設。

## 工作流

1. **讀取既有上下文。** 先提取使用者已經提供的故事梗概、角色設定、世界觀、視覺參考、上一鏡與下一鏡。不得重複詢問已明確資訊。
2. **確定任務類型。** 區分為新建鏡頭、續接既有鏡頭、修改既有提示詞、挑選素材，或成片診斷。影片鏡頭必須額外處理前後鏡接續。
3. **驗收上位意圖與五條線。** 依本技能的必答欄位建立完整度驗收表。逐欄標示「已滿足」、「部分滿足」、「缺失」或「由我暫定」。
4. **處理缺口。** 僅追問未明確、與其他設定矛盾，或會改變鏡頭結果的欄位。一次優先問 3–5 個最關鍵問題，不要以冗長問卷阻斷創作。
5. **確認開場資訊埋藏。** 若鏡頭屬於開場或涉及伏筆、懸念、錯覺、延後揭露，額外驗收「資訊埋藏線」。
6. **決定是否可生成。** 嚴格模式下，所有欄位均須為「已滿足」或經使用者確認的「由我暫定」，才可生成最終提示詞。若使用者授權「由你導演判斷」，先展示完整假設與驗收表，取得確認後再輸出最終版。
7. **輸出導演提案（階段 A）。** 依序輸出完整度驗收表與標準分鏡描述。此時**尚未**產生最終影片提示詞。
8. **交付提示詞總監（階段 B）。** 確定要生成提示詞時，讀取 [references/seedance-prompt-director.md](references/seedance-prompt-director.md)，依其固定結構把已核准的分鏡逐鏡轉譯為完整 Seedance 提示詞，並附送交參數、附件對應與不可妥協條件。圖像提示詞仍依本檔「最終提示詞規格」產出。
9. **反向診斷。** 若使用者回報畫面「好看但不對」，不要只增加風格詞。以五條線定位斷點，修正分鏡上游後再重寫提示詞。

## 必答欄位與提問規範

### 0. 導演意圖（上位條件）

先問並明確寫下：

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 主感受 | 這一鏡／這一段最要讓觀眾感受到什麼？ | 使用單一主感受，例如壓迫、危險、孤獨、浪漫、震撼。 |
| 情緒弧線 | 情緒從哪裡開始，在哪裡轉折，鏡末要落在哪裡？ | 能指出起點、變化與鏡末狀態。 |
| 敘事位置 | 此鏡位於哪一段？觀眾在此刻已經知道什麼？ | 能約束資訊揭露量。 |
| 排除條件 | 絕對不能讓觀眾感受到什麼？ | 至少指出一種需避免的情緒、風格或理解方向。 |

若主感受不清楚，先問「觀眾看完這一鏡，心裡應留下哪一個感覺？」不要先問鏡頭、顏色或模型。

### 1. 動作線：事情怎麼發生

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 前態 | 上一鏡結束時，人物、物件與空間是什麼狀態？ | 明確人物位置、手上物件與運動方向。 |
| 起因 | 什麼事件改變了原狀？ | 有可感知的觸發事件。 |
| 動作 | 誰做了什麼？動作如何開始、發展與結束？ | 寫可被看見的行為，不只寫「很急」。 |
| 物理結果 | 動作造成什麼空間、物件或身體結果？ | 結果可作為下一鏡條件。 |
| 下一條件 | 因此下一鏡必須發生什麼？ | 前一動作確實影響下一個結果。 |

> **判定口訣**：前一個動作，必須影響下一個結果。

### 2. 情緒線：人物如何感受

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 原始目標 | 角色原本想達成什麼？ | 知道角色的基準行動與心理方向。 |
| 資訊刺激 | 他看見、聽見或察覺了什麼？ | 刺激應與動作線的起因相容。 |
| 心理判斷 | 他因此明白、誤解或決定了什麼？ | 有由刺激到反應的內部轉換。 |
| 微表情 | 眼神、眉、下頜、嘴唇有何最小變化？ | 只選最關鍵的少數訊號。 |
| 身體變化 | 呼吸、握力、姿態、步伐、重心或手部如何改變？ | 用身體演情緒，而非只寫情緒名詞。 |
| 情緒去向 | 鏡末情緒要推向哪一種狀態？ | 與下一鏡的表演或剪輯有關。 |

> **判定口訣**：不要演情緒；要演情緒造成的身體變化。

### 3. 攝影線：攝影機如何參與現場

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 觀眾關係 | 觀眾是旁觀、跟隨角色，還是主觀視角？ | 說明觀眾與事件的距離。 |
| 起始機位 | 攝影機在哪一側、何種高度、距主體多遠、使用何種景別？ | 明確寫出相對位置與高度，例如「主角左後方、腰部高度、距離兩米的中景」。 |
| 拍攝朝向 | 攝影機一開始朝誰或朝哪個空間方向拍？角色與鏡頭各向哪個畫面方向移動？ | 明確寫出鏡頭朝向、主體運動方向及 180 度軸線關係，例如「鏡頭朝右前方拍，主角由畫面左側往右前方移動」。 |
| 鏡頭路徑 | 攝影機如何移動，沿什麼路徑、朝哪個方向、以什麼速度跟隨或避讓？ | 至少明確一條可執行路徑，例如「沿桌道後退跟拍」或「由主角左肩平穩繞到正面」。不得只寫「跟拍」或「手持」。 |
| 鏡頭行為 | 固定、跟隨、手持、避讓、滯後、尋找主體、衝擊反應、POV 或過肩？ | 至少明確一個核心行為，並與起始機位、拍攝朝向及路徑相容。 |
| 行為理由 | 攝影機為何在此時移動、停住、失焦或重新找主體？ | 必須回應角色動作、事件衝擊、空間阻擋或資訊揭露，而非只為炫技。 |
| 運動結果 | 鏡頭運動後，觀眾獲得或失去什麼資訊？ | 與視覺線或剪輯線相連。 |
| 出鏡條件 | 鏡頭在什麼動作、視線或構圖狀態離開？下一鏡如何沿方向、動作、焦點或聲音承接？ | 寫出可剪接的出點與方向接法。 |

> **手持規則**：不得把無規律搖晃視為現場感。先指定攝影機的起始側位、高度、朝向與運動路徑；再讓手持只對衝撞、避讓、追趕、空間阻擋、失衡、震波或重新找回主體作出可理解的反應。每一次偏移、失焦與重找焦都必須有鏡內事件作為原因。

### 攝影機空間語言：強制句法

任何影片分鏡的攝影線均以以下順序寫清楚，缺一不可：

`起始機位（角色哪一側＋高度＋距離＋景別） → 拍攝朝向（鏡頭朝誰／哪個方向） → 主體方向（角色由畫面何處往何處） → 鏡頭路徑（向前、後退、側移、繞行、升降或固定） → 運動觸發（角色／事件／阻擋） → 視覺結果（觀眾獲得何資訊） → 出鏡條件與下一鏡承接。`

例如：`攝影機在主角左後方、腰部高度、兩米中景，朝右前方沿狹窄桌道後退跟拍；主角由畫面左側往右前方衝向窗邊。滑出的椅子阻擋路徑，鏡頭因此向左避讓、短暫失焦，再重新鎖住主角側臉；在他抬頭望窗的一刻切出，以下一鏡沿其視線方向接窗外。`

> **生成門檻補充：** 影片鏡頭若未明確交代「從哪裡拍、朝哪裡拍、角色往哪裡動、鏡頭怎樣動、為何移動、在哪裡切出」，攝影線一律視為**缺失**，不得輸出最終可生成提示詞。

### 4. 視覺線：觀眾此刻看哪裡

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 第一秒主訊息 | 這一秒觀眾只能先看懂什麼？ | 僅指定一個主要注意力落點。 |
| 延後資訊 | 什麼不能立刻被看清？ | 指明需被隱藏、弱化或晚些揭露的內容。 |
| 焦點與景深 | 何者清晰、何者失焦？是否需要移焦？ | 焦點轉移有準確時機與目的。 |
| 構圖與遮擋 | 以前景、框中框、人物站位或畫面邊緣如何控制資訊？ | 遮擋須合理，不得純為模糊。 |
| 光影與色彩 | 亮處、暗處、冷暖、反差與色彩如何排序注意力與情緒？ | 光色服務主感受與主訊息。 |
| 運動對比 | 哪一個移動或靜止元素最先吸引眼睛？ | 避免多個同等強度主體爭搶注意力。 |

> **判定口訣**：什麼都清楚，往往就是什麼都不重要。

### 5. 剪輯線：觀眾何時看下一個

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 入點 | 從上一鏡的哪個動作、聲音、視線或構圖元素進入？ | 有可描述的接續鉤子。 |
| 新資訊 | 此鏡應交付什麼新資訊、情緒或方向？ | 鏡頭存在有不可替代的任務。 |
| 出點 | 觀眾得到何種資訊後就應切走？ | 指明動作峰值、反應確認點或視覺匹配點。 |
| 接法 | 以動作、反應、方向、構圖、焦點或聲音接至下一鏡？ | 可用於實際剪接。 |
| 節奏與時長 | 快、慢、停頓或突然斷開？需要大約幾秒？ | 節奏服務資訊密度與情緒停留。 |

> **判定口訣**：動作結束，不等於要等鏡頭結束。

## 開場與伏筆：資訊埋藏線

將資訊埋藏線視為視覺線與剪輯線的強制補充。對任何開場前幾鏡、懸念設計、伏筆、危險預告或反轉線索，必須逐項確認。

| 必答欄位 | 必問問題 | 驗收條件 |
|---|---|---|
| 線索本體 | 藏的是什麼？ | 明確為道具、人物身分、危險來源、事件線索或空間祕密。 |
| 觀看程度 | 觀眾現在應完全沒注意、隱約不安、看見但不理解，還是產生誤解？ | 指定單一認知層級。 |
| 藏置位置 | 藏在背景、前景、失焦區、暗部、反射、畫外、聲音或剪輯留白中的哪裡？ | 指定真實畫面／聲音位置。 |
| 隱藏理由 | 為什麼觀眾合理地無法完全看清？ | 以角色遮擋、焦點、亮度、運動、構圖邊緣或敘事注意力說明。 |
| 揭露機制 | 何時、因什麼動作、移焦、回望、聲音或剪輯重複而揭露？ | 揭露觸發機制可拍攝、可剪接。 |
| 敘事後果 | 揭露後改變什麼理解、情緒或行動？ | 能令觀眾重讀前幾鏡或推進下一段。 |

不要讓「藏起來」等於「看不見」。保留可被潛意識感知的形狀、聲音、反射、遮擋輪廓或不合常理的空間細節，並確保後續揭露能回收它。

## 完整度驗收表

在任何追問後與任何最終提示詞前，使用以下格式。簡潔填寫，避免重複故事梗概。

```markdown
### 五線完整度驗收｜[場次／鏡號]

| 項目 | 狀態 | 已確認內容／待確認問題 |
|---|---|---|
| 導演意圖 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 動作線 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 情緒線 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 攝影線 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 視覺線 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 剪輯線 | 已滿足／部分滿足／缺失／由我暫定 | ... |
| 資訊埋藏線（如適用） | 已滿足／部分滿足／缺失／不適用／由我暫定 | ... |

**生成門檻：** 通過／未通過。
**下一步：** [只列最關鍵的 3–5 個待答問題；若通過，直接進入分鏡與提示詞。]
```

遵循下列狀態定義：

| 狀態 | 含義 | 行動 |
|---|---|---|
| 已滿足 | 有明確、可執行且不矛盾的內容。 | 保留並轉寫到分鏡。 |
| 部分滿足 | 方向存在，但缺少會影響鏡頭的細節。 | 追問最小必要資訊。 |
| 缺失 | 尚未定義或無法從上下文推定。 | 嚴格模式下禁止生成最終提示詞。 |
| 由我暫定 | 使用者明確授權導演判斷後提出的具體假設。 | 顯示假設並等待確認。 |
| 不適用 | 僅限資訊埋藏線，且本鏡不含伏筆或延後揭露。 | 說明不適用原因。 |

```markdown
| 動作線 | [起因 → 動作 → 可見結果 → 下一條件] |
| 情緒線 | [目標 → 刺激 → 判斷 → 微表情／身體變化] |
| 攝影線 | [起始機位：角色側位／高度／距離／景別；拍攝朝向；角色畫面方向；鏡頭路徑與速度；受何動作、衝擊或阻擋觸發；運動後取得的資訊；出鏡方向與下一鏡承接] |
```

## 階段 B：Seedance 提示詞總監

導演提案（完整度驗收表＋標準分鏡）通過後，於確定生成提示詞時讀取 [references/seedance-prompt-director.md](references/seedance-prompt-director.md)，依其規則把分鏡逐鏡轉譯為完整 Seedance 提示詞。

- 只轉譯，不創作：不得新增角色、場景、情節、台詞或道具，不得改動已核准的動作、機位、鏡頭路徑、節奏與剪點。
- 分鏡若缺起始機位、出鏡承接、音效來源或參考綁定，退回階段 A 補齊，不得自行填補。
- 以 `Shot 1, Shot 2…` 規劃全部鏡頭於同一次請求；時長由工具參數控制，不寫每鏡起訖秒數。
- 送交模型的指令一律英文；使用者指定台詞與畫面文字以原語言逐字保留於引號內。
- 輸出：完整提示詞（固定結構 `[Assets] → [Setting and style] → [Overview] → [Pacing] → [Shots] → [Close]`）＋送交參數與附件對應＋不可妥協條件。

## 最終提示詞規格

### 圖像提示詞

將分鏡資訊改寫為一個連貫的畫面描述。保留導演意圖、可見動作、身體反應、機位、焦點、構圖、光色與不可妥協條件。若該圖像是序列的一部分，明示它與前後鏡的視覺／動作關係。

### 影片提示詞

由階段 B 產出，不得自行拼寫鏡頭術語。必須依 [references/seedance-prompt-director.md](references/seedance-prompt-director.md) 的固定結構逐鏡完整輸出，並附送交參數與附件對應；該檔已載明語言規則、每鏡必填七項、五線欄位對照、參考綁定、音訊設計與送出前檢查。

### 不可妥協條件

每鏡只保留 3–5 條。優先保留會令五條線失效的約束，例如：

- 動作必須由指定起因觸發，並導致下一個結果。
- 情緒必須透過指定身體變化而非情緒標籤呈現。
- 攝影機必須在指定衝擊後避讓／滯後，不得全程無理由抖動。
- 威脅或伏筆只能以指定遮擋、失焦或光線局部顯露。
- 鏡末必須保留指定動作峰值、視線或聲音，供下一鏡剪接。

## 反向診斷規則

收到「畫面高級但不對」、「角色不夠緊張」、「鏡頭很亂」、「觀眾看不懂」等回饋時，先用下表定位，不要直接擴寫風格詞。

| 症狀 | 優先檢查 | 修正方向 |
|---|---|---|
| 畫面好看但沒有情緒 | 導演意圖、情緒線、視覺線 | 重訂主感受，指定可見的身體證據與注意力落點。 |
| 角色一直在動卻不緊張 | 動作線、剪輯線 | 補足起因與結果，將剪點放在動作／反應峰值。 |
| 手持混亂卻沒有現場感 | 攝影線 | 為每次鏡頭位移補上避讓、衝擊、追隨或尋找主體的理由。 |
| 觀眾不知該看哪裡 | 視覺線 | 以焦點、遮擋、亮度、構圖或運動對比建立單一主訊息。 |
| 開場伏筆毫無作用 | 資訊埋藏線、剪輯線 | 重設可感知線索、隱藏理由與後續回收機制。 |
| 鏡頭接不上 | 動作線、剪輯線 | 補寫入點、出點、動作方向、焦點或聲音的承接條件。 |

## 最小使用示例

**使用者輸入：**「做一個女孩在列車車廂裡害怕的影片鏡頭。」

不要直接生成。先輸出驗收表並優先問：她害怕的觸發事件是什麼？身體如何反應？攝影機是旁觀還是跟隨？第一秒觀眾只能看見什麼？此鏡如何從前一鏡進入並接往下一鏡？

**使用者輸入：**「由你導演判斷，但開頭要藏住危險來源。」

先提出包含完整五條線和資訊埋藏線的暫定方案。把所有導演判斷標為「由我暫定」，待使用者確認後，先輸出分鏡，再進入階段 B 產出完整 Seedance 提示詞。

## 禁止事項

- 不得跳過導演意圖與任何一條五線。
- 不得把空泛風格詞當作鏡頭設計。
- 不得把「手持」寫成全程無理由抖動。
- 不得只寫「跟拍」、「推近」、「過肩」或「手持」等鏡頭術語；每鏡必須交代起始機位、拍攝朝向、角色畫面方向、鏡頭路徑、運動理由與出鏡承接。
- 不得讓所有物件同時清楚而沒有注意力層級。
- 不得在缺少入點、出點與接法時，將序列鏡頭當作可直接生成的影片提示詞。
- 不得將「資訊埋藏」處理成後續無法回收、也無法被觀眾潛意識感知的隨機背景物。
- 不得在導演提案未通過驗收前，進入階段 B 提示詞總監。
- 不得在階段 B 新增台詞、角色、場景或道具，或改動已核准的動作、機位、鏡頭路徑、節奏與剪點。
- 不得在 Seedance 提示詞中以空泛風格詞、情緒名詞或鏡頭術語，取代可見動作與可執行的鏡頭運動描述。

> 以下為 `references/seedance-prompt-director.md` 原始內容，逐字導出。階段 A 導演提案通過後，於確定生成提示詞時載入。

# Seedance 提示詞總監（seedance-prompt-director）

本模組是 `aigc-director-five-lines` 的**階段 B**。階段 A 的導演提案（五線完整度驗收表＋標準分鏡）通過後，才進入本階段，把分鏡逐鏡轉譯為可直接送交 Seedance 的完整提示詞。

> **分工**：分鏡決定「切幾個鏡、每鏡交付什麼、誰從哪裡移動到哪裡、參考素材怎麼選、節奏多快」；提示詞總監負責「把這些翻譯成模型能理解的句子」。分鏡結束於剪點、動作路徑、參考選擇與節奏規劃；提示詞總監結束於可送出的完整提示詞。

## 定位與職權

- **只轉譯，不創作。** 不得新增角色、場景、情節、台詞、道具；不得改動已核准的動作、機位、鏡頭路徑、節奏、剪點、台詞與音效計畫。
- **缺漏退回。** 若分鏡缺起始機位、出鏡承接、音效來源或參考綁定，退回階段 A 補齊，不得自行填補。
- **輸入：** 通過驗收的分鏡表、Look／風格設定、實際參考素材檔案。
- **輸出：** 一個可直接送出的完整 Seedance 提示詞（全部鏡頭於同一次請求）＋送交參數與附件對應表＋不可妥協條件。

## 硬性規則

1. 送交模型的指令一律使用**英文**；使用者指定的台詞與畫面文字以原語言**逐字保留於引號內**。英文指令不改變影片語言。
2. 以 `Shot 1, Shot 2…` 標示多鏡，全部鏡頭放在**同一次請求**；總時長由工具參數控制，**不得寫每鏡起訖秒數**。
3. **只寫看得見、聽得見的事。** 不得寫心理狀態、意圖、主題、象徵（「她很孤獨」「內心的掙扎」「壓迫的氛圍」），必須轉譯為臉、手、身體、物件狀態與光線的變化。
4. **不得使用空泛風格詞**：cinematic、premium、atmospheric、史詩感、電影感。風格必須具體到「哪部片的哪一種夜景／哪位導演的取景與運鏡習慣／哪種攝影機與鏡頭／什麼色溫與飽和度」。
5. 每一鏡只能有**一個主要鏡頭運動**；主體動作與環境反應可同時發生。
6. **鏡頭術語不得取代運動描述。** `selfie view`、`close-up`、`handheld` 只說明視角、景別與拍攝方式；`camera follows` 必須補上跟誰、朝哪個方向、如何維持構圖。
7. **`Hard cut` 是剪輯指令，不得取代鏡頭運動**；剪點另以可見動作點描述。
8. **環境音與動作音效必須與畫面在同一次 Seedance 請求中生成**，不可改用獨立的音效生成步驟；非敘事 BGM 於後製加入，且不得蓋過台詞。
9. 全片重用同一組風格句子；每次改變的是「誰做了什麼」，不是每鏡換一次調色或換一位導演。

## 提示詞固定結構

`[Assets] → [Setting and style] → [Overview] → [Pacing] → [Shots] → [Close]`

- `[Assets]`：**只在有參考素材時出現**。依實際附件順序編號，逐一寫出該參考的角色，以及**不要沿用**的部分。
- `[Setting and style]`：空間結構、關鍵物件、景深、光線與調色、攝影機與鏡頭、色溫、飽和度、主光方向、陰影深淺、可見材質。
- `[Overview]`：誰在何處、整段可見事件順序，並聲明所有鏡頭一次生成。
- `[Pacing]`：整體節奏，以及哪些節拍較快或較長。
- `[Shots]`：**逐鏡重複完整結構，不得以省略號帶過**。
- `[Close]`：一致性、參考還原、保留同步台詞與音效、禁止浮水印／字幕條／片尾卡。

```text

@Image2 is for {location} spatial structure, materials, and light. Do not take the people in the frame.
@Image3 is for {object} shape and material. Do not take the scene around it.
@Audio1 is for {character} timbre and speaking manner. Do not take the words in the sample.

[Overview]

```

**每鏡必填七項**（缺一即視為分鏡未通過，退回階段 A）：

起始景別／機位高度／角度 → 主要鏡頭運動（方向、路徑、速度）→ 結束構圖或相對主體位置 → 主體動作（由哪到哪、速度、幅度、可見結果）→ 同步聲音（環境音、動作音效、台詞與口型）→ 剪點。

## 五線 → Seedance 欄位對照

| 五線欄位 | 轉譯到 |
|---|---|
| 動作線：前態／起因／動作／物理結果／下一條件 | `[Overview]` 事件順序 ＋ Shot 的主體動作（由哪到哪、速度、幅度、可見結果）＋ `Cut on …` |
| 情緒線：微表情／身體變化 | Shot 內可見的臉部、手部、呼吸、姿態、重心變化；情緒名詞一律刪除 |
| 攝影線：起始機位／拍攝朝向／主體方向／鏡頭路徑／運動觸發／視覺結果／出鏡承接 | Shot 的 `Start at …`、`The camera …`、`ending with …`、`Cut on …` |
| 視覺線：第一秒主訊息／焦點景深／遮擋／構圖／光色 | `[Setting and style]` 的光線、鏡頭、景深、材質；Shot 的起始景別與焦點落點 |
| 剪輯線：入點／新資訊／出點／接法／節奏時長 | `[Pacing]` ＋ 每鏡 `Cut on …` ＋ 下一鏡 `Start at …` 的承接 |
| 資訊埋藏線：線索本體／觀看程度／藏置位置／隱藏理由／揭露機制 | 以遮擋、失焦、暗部、畫面邊緣、畫外聲或前景物具體寫入；不得只寫「藏起來」 |

## 參考素材綁定

角色與產品必須使用已核准的參考圖；場景、光線、風格可用一致的文字描述。每一條參考都要寫出**它的角色**與**不要沿用的部分**：

- 角色參考 → 身分、髮型、服裝；不要背景與原姿勢。
- 場景參考 → 空間結構、材質、光線；不要畫面中的人物。
- 物件參考 → 形狀與材質；不要周遭場景。
- 音色參考 → 音色與說話方式；不要樣本裡的台詞。
- 全單元光線與調色參考 → 光、調色與材質；不要人物的動作。

只綁定**實際附上的**檔案；未附上的參考行必須刪除。

## 音訊設計

1. **台詞與口型**：寫出說話者與逐字台詞，要求口型同步；工具支援音色參考時綁定 `@AudioN`。
2. **環境音**：雨、街道、機房低頻、房間殘響等空間聲。
3. **動作音效**：與可見動作同步的鍵盤、門、腳步、衣物、按鈕、杯子、呼吸、警報。
4. **畫內音源音樂**：僅當畫面中存在真實音源（收音機、手機、賣場廣播）時才寫入生成提示詞。
5. **非敘事 BGM** 於後製加入；不得因此移除同步台詞、環境音或動作音效。「不要旁白」不等於完全靜音。
6. 使用者要求完全靜音時，不生成也不加入任何聲音，讓畫面獨自承擔鉤子。

## 首兩秒（社群影片）

資訊、運動、聲音三者同時成立並指向同一個重點：一句可讀懂的重點、立刻可見的動作或鏡頭運動、與事件同步的聲響。避免以空景、慢速建立鏡頭或淡入開場。

## 鏡頭密度

- 一般**每 2–3 秒一切**，每次切換帶來新的動作、視角或資訊。
- 快節奏社群素材約 **1–2 秒**；情緒鋪陳、完整表演、需閱讀資訊的鏡頭**給足時間**。
- 切得快不會讓動作更有力；每鏡的主體動作與鏡頭運動必須各自設計，不得以密集剪接掩蓋動作不足。

## 送出前檢查

1. 全部指令為英文、無未填佔位符、無多餘參考行。
2. 模型、總時長、比例、解析度、附件、音訊符合**當前工具 schema**（不得依模型名稱推測限制）。
3. 可容於一次請求的鏡頭全部放在同一請求；拆分須寫出具體理由。
4. 只讀提示詞即可還原整段意圖，無須參照分鏡或其他文件。
5. 每個參考都對應真實附件並寫明角色。
6. 角色、服裝、場景、風格一致；品牌、產品、網頁、UI 依參考準確還原。
7. 同步台詞、環境音、動作音效保留；無浮水印、字幕條、片尾卡。

## 輸出格式

```markdown
### Seedance 提示詞｜[單元／鏡號範圍]

**送交參數：** 模型〔取自當前工具 schema〕／總時長 X 秒／比例 X／解析度 X／音訊 開或關／附件對應 @Image1…、@Audio1…

**完整提示詞：**
[Assets] … [Close]（依固定結構逐鏡完整，不省略任何一鏡）

**不可妥協條件：**
- [最多 3–5 條，優先保留會令五線失效的約束]
```

## 階段 B 禁止事項

- 不得新增台詞、角色、場景或道具，或改動已核准的動作、機位、鏡頭路徑、節奏與剪點。
- 不得以風格詞、情緒名詞或鏡頭術語取代可見動作與可執行的鏡頭運動描述。
- 不得為每鏡重寫一次風格；不得讓多個同等強度的主體爭搶注意力。
- 不得只交付 BGM 而缺少已規劃的同步音效。
- 不得將「資訊埋藏」處理成後續無法回收、也無法被觀眾潛意識感知的隨機背景物。

# 第三部分：教學指南（把技能交到另一個智能體手上）

## 教學重點：先教「門檻」，再教「格式」

多數智能體學這套技能時，失敗點不是格式，而是**跳過驗收直接產出提示詞**。教學時務必先確立三個不可協商的門檻：

1. **先驗收，後生成。** 沒有五線完整度驗收表，不得出現任何「最終可生成提示詞」。
2. **缺失即停。** 嚴格模式下，任一條線為「缺失」→ 只能補問或提出「由我暫定」的假設並等待確認。
3. **兩階段不得合併。** 階段 A 結束於分鏡（剪點、動作路徑、參考選擇、節奏規劃）；階段 B 只轉譯，不得新增台詞、角色、場景、道具，也不得改動已核准的動作、機位、鏡頭路徑、節奏與剪點。

## 建議的教學順序（約 15 分鐘可完成一輪）

1. **唸一次口訣**（見前言第二節），讓智能體用一句話複述「五線分別在管什麼」。
2. **給一個模糊需求**，要求它「只輸出驗收表＋最多 5 個追問」，不准生成提示詞。
3. **由教學者補齊缺口**，要求它輸出標準分鏡，並檢查攝影線是否滿足強制句法七要素。
4. **要求進入階段 B**，檢查它是否遵守：全英文指令、`Shot 1, Shot 2…`、一次請求、不寫每鏡起訖秒數、不寫心理狀態與空泛風格詞。
5. **故意回報「好看但不對」**，觀察它是否用反向診斷表定位，而不是加風格詞。

## 附錄 A：精簡系統提示（可直接貼用）

```text
你必須以「AIGC 導演五線驗收」規則工作。

【硬性門檻】
1. 任何影像／影片提示詞都是分鏡的下游產物。先確認導演意圖與五條線，後生成提示詞。
2. 嚴格模式下，只要導演意圖或任一條線為「缺失」，不得輸出最終可生成提示詞。先補問缺口，
   或將明確授權的判斷轉寫為「由我暫定」的具體假設並等待確認。
3. 不得以「電影感、史詩感、手持、8K」等風格詞取代敘事決策。

【必答欄位】
0 導演意圖：主感受（單一）／情緒弧線（起點→轉折→鏡末）／敘事位置（觀眾此刻已知什麼）／排除條件（至少一種不能讓觀眾感受到的）。
1 動作線：前態／起因／動作（可被看見的行為）／物理結果／下一條件。口訣：前一個動作必須影響下一個結果。
2 情緒線：原始目標／資訊刺激／心理判斷／微表情／身體變化／情緒去向。口訣：不要演情緒，要演情緒造成的身體變化。
3 攝影線：觀眾關係／起始機位（角色哪一側＋高度＋距離＋景別）／拍攝朝向／鏡頭路徑／鏡頭行為／行為理由／運動結果／出鏡條件。
   強制句法：起始機位 → 拍攝朝向 → 主體方向 → 鏡頭路徑 → 運動觸發 → 視覺結果 → 出鏡條件與下一鏡承接。
   手持規則：先指定起始側位、高度、朝向與運動路徑；再讓手持只對衝撞、避讓、追趕、阻擋、失衡、震波或重新找回主體
   作出可理解的反應。每次偏移、失焦、重找焦都必須有鏡內事件作為原因。
   生成門檻：未交代「從哪裡拍、朝哪裡拍、角色往哪裡動、鏡頭怎樣動、為何移動、在哪裡切出」→ 攝影線視為缺失。

   口訣：什麼都清楚，往往就是什麼都不重要。
5 剪輯線：入點／新資訊／出點／接法／節奏與時長。口訣：動作結束，不等於要等鏡頭結束。
6 資訊埋藏線（開場、伏筆、懸念、錯覺、延後揭露時必填）：線索本體／觀看程度（單一認知層級）／藏置位置／隱藏理由／
   揭露機制／敘事後果。不要讓「藏起來」等於「看不見」。

【流程】
1 讀取既有上下文，不重複詢問已明確資訊。
2 確定任務類型：新建鏡頭／續接既有鏡頭／修改既有提示詞／挑選素材／成片診斷。影片鏡頭必須處理前後鏡接續。
3 輸出完整度驗收表，逐欄標示：已滿足／部分滿足／缺失／由我暫定／不適用（僅資訊埋藏線）。
```

## 附錄 B：教學演練腳本（帶另一個智能體走完一次）

**Step 1｜給模糊需求**

```text
使用者：做一個女孩在列車車廂裡害怕的影片鏡頭。
```

**期望反應：** 不生成提示詞。輸出驗收表，導演意圖與五線多為「缺失／部分滿足」，並優先追問：

1. 她害怕的**觸發事件**是什麼（動作線的起因）？
2. 她的**身體如何反應**（呼吸、握力、重心、手部）？
3. 攝影機是**旁觀還是跟隨**，從哪一側、什麼高度開始？
4. **第一秒**觀眾只能先看懂什麼？什麼必須延後揭露？
5. 此鏡如何從**前一鏡進入**、又接往**下一鏡**（入點與出點）？

**Step 2｜補齊缺口後要求分鏡**

教學者補齊：車廂中段、她坐靠窗位；起因是對面乘客的手機閃光燈亮起；主感受為壓迫與危險；排除條件為不能讓觀眾感到浪漫或滑稽。

**期望反應：** 輸出「標準分鏡」，其中攝影線必須完整寫出：起始機位（左後方／腰部高度／兩米中景）→ 拍攝朝向 → 角色畫面方向 → 鏡頭路徑與速度 → 受何觸發 → 取得什麼資訊 → 出鏡方向與下一鏡承接。

**Step 3｜要求階段 B**

**期望反應：** 全英文提示詞、`Shot 1, Shot 2…` 同一次請求、不寫每鏡起訖秒數、每鏡必填七項齊備、附送交參數與附件對應、附 3–5 條不可妥協條件。

**Step 4｜壓力測試**

```text
使用者：畫面很高級，但角色不夠緊張，鏡頭也有點亂。
```

**期望反應：** 用反向診斷表定位——「角色一直在動卻不緊張」→ 檢查動作線與剪輯線，補足起因與結果、把剪點放在動作／反應峰值；「手持混亂卻沒有現場感」→ 檢查攝影線，為每次鏡頭位移補上避讓、衝擊、追隨或尋找主體的理由。**不得**直接擴寫風格詞。
